# Guion para un video de demostración auténtico (2–3 min)

El guion no equivale a un video grabado. Debes capturar la aplicación **ejecutándose en la URL real** para atribuirle evidencia visual.

| Minuto aprox. | Acción real a mostrar | Qué demuestra |
| --- | --- | --- |
| 00:00–00:15 | Abrir URL de Render y `api/health` | Aplicación publicada, no archivo local |
| 00:15–00:40 | Ingresar como jefatura y registrar falla ficticia | RF-01/02; folio |
| 00:40–01:05 | Cambiar a coordinación; asignar técnico y orden | RF-06/07; permisos |
| 01:05–01:25 | Técnico reporta reparación ficticia | RF-11; estado pendiente Vo.Bo. |
| 01:25–01:45 | Jefatura revisa y acepta | RF-12 y RN-05 |
| 01:45–02:00 | Coordinación cierra; Planeación exporta | RF-13/14 |
| 02:00–02:15 | Mostrar historial y prueba del cierre bloqueado | RF-17 y RNF-07 |
| 02:15–02:30 | Mostrar pantalla SUS (sin inventar usuarios) | Instrumento de evaluación real |
